# ruckus_fw_autodownloader_enhanced
루커스 제품 다운로더 및 루커스 언리시드 전용 다운로더

1) 윈도우용
---------------------------------------------------------------
#루커스 제품 다운로더(윈도우용)
: auto_ruckus_downloader.zip

#루커스 언리시드 펌웨어 전용 다운로더(윈도우용)
: auto_ruckus_unleashed_downloader.zip

---------------------------------------------------------------
※ 주의 : 윈도우용 스크립트 파일의 경우 오류시 파일의 인코딩을 utf8-bom으로 변경해야함.

<br>

2) 리눅스용
---------------------------------------------------------------
#루커스 제품 다운로더(리눅스용-Rocky8)
: auto_ruckus_downloader_linux.tar

#루커스 언리시드 펌웨어 전용 다운로더(리눅스용-Rocky8)
: auto_ruckus_unleashed_downloader_linux.tar
---------------------------------------------------------------

<br>

3) 사용방법
---------------------------------------------------------------
3-1) 윈도우
해당 zip파일을 아무 폴더에 압축해제한 후 

run_downloader.bat 
또는
run_unleashed_downloader.bat
을 실행하면 됨.

<br>

3-2) 리눅스
해당  tar 파일을  각각 아무 폴더에 압축해제한 후

run_downloader_linux.sh
또는
run_unleashed_downloader_linux.sh
을 실행하면 됨.

※ 다운로드를 위해 Ruckus support 계정 필요.
