# ruckus_fw_autodownloader_enhanced(윈도우용)
루커스 제품 다운로더 및 루커스 언리시드 전용 다운로더

#루커스 제품 다운로더(윈도우용)
: auto_ruckus_downloader.zip

#루커스 제품 다운로더(리눅스용-Rocky8)
: auto_ruckus_downloader_linux.tar

#루커스 언리시드 펌웨어 전용 다운로더(윈도우용)
: auto_ruckus_unleashed_downloader.zip

#루커스 언리시드 펌웨어 전용 다운로더(리눅스용-Rocky8)
: auto_ruckus_unleashed_downloader_linux.tar

해당 zip, tar 파일을 운영체제에 맞게 각각 아무 폴더에 압축해제한 후 

1) 윈도우에서는 run_downloader.bat 또는 run_unleashed_downloader.bat을 실행하면 됨.

2) 리눅스에서는 auto_ruckus_downloader_linux.sh 또는 auto_ruckus_unleashed_downloader_linux.sh 파일을 실행하면 됨.

다운로드를 위해 Ruckus support 계정 필요.
